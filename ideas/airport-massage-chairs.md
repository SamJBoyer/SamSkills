# Skill proposal: Airport massage chairs

**Working name:** `airport-massage-chairs`

**When to use:** When the user wants to find massage chairs (or similar paid lounge seating) in an airport — before a flight, during a layover, or while already at the terminal.

## Rough steps
1. Confirm airport (IATA code or name) and, if known, terminal / concourse / gate area.
2. Search airport maps, official terminal guides, and traveler reports for massage chairs, massage stations, or paid rest seating.
3. Prefer sources that name a specific location (terminal, gate cluster, near restrooms/food court).
4. Note hours, payment, and any access limits (airside only, lounge-adjacent, etc.) when available.
5. Return a short list ranked by closeness to the user’s current or planned spot, with links or map cues when possible.

## Open questions
- Prefer official airport maps only, or also traveler apps / Reddit / blogs?
- Should this cover related “rest” options (nap pods, quiet rooms) or stay massage-chairs-only?
- Any home airports or frequent hubs to hard-code first?
